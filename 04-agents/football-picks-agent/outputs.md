## Daddy Dan's Picks visual card (retired 2026-10-13: no graphic output, text cards only)

Every completed weekly run produces a branded portrait pair:

```text
05-outputs/reports/football-picks-agent/daddy-dans-picks-<date>.html
05-outputs/reports/football-picks-agent/daddy-dans-picks-<date>.png
```

`render-weekly-visual.py` reads the exact `Paste to iMessage` block from the
weekly markdown card, layers it over the selected empty fan-cave background,
and renders a 1024 × 1536 PNG. The approved visual system lives in
`03-projects/football-picks-agent/visual-design-language.md`; themed background
changes never rewrite picks or numbers.
